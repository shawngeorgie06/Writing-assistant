# Writing Assistant - Quick Start Guide

## 1. Start the App (30 seconds)

```bash
cd C:\Users\georg\Documents\Writing-assistant
python app.py
```

Wait for this message:
```
 * Running on http://127.0.0.1:5000
```

Then open your browser to: **http://127.0.0.1:5000**

## 2. Login or Register

### Option A: Use Demo Account (fastest)
- Email: `demo@example.com`
- Password: `demo123`
- Click "Continue as Guest" button

### Option B: Create New Account
1. Click "Sign Up" tab
2. Enter username, email, password
3. Click "Create Account"

## 3. Start Writing

1. **Create a new document**
   - Click "New Document" in the sidebar
   - Or open an existing document

2. **Write your content**
   - Type or paste your text in the main editor
   - Auto-saves every 1.5 seconds (look for "Saved" indicator)

3. **See Real-Time Analysis**
   - As you type, writing suggestions appear on the right panel
   - Shows clarity score, style score, and specific issues

4. **Format Your Text**
   - Select text and use the toolbar buttons
   - Bold, Italic, Underline, Alignment options

5. **Export Your Work**
   - Click "Export as PDF" to download PDF
   - Click "Export as Markdown" to download MD file

## 4. Explore Features

- **Sidebar Toggle**: Click hamburger menu (≡) to open/close sidebar
- **Document List**: See all your documents in the sidebar
- **Statistics**: Check word count, reading time, etc.
- **Version History**: Restore previous versions of your document
- **Search**: Find documents by title (sidebar search box)

## 5. Stop the App

Press `Ctrl+C` in the terminal to stop the server.

---

## That's It!

The application auto-saves your work and analyzes as you write. Enjoy!

**Pro Tip**: The sidebar stays open while you work. Click the hamburger menu to collapse it and get more writing space.
